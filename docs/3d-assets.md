The original model is bundled locally so it does not require an external model request at runtime. Its scale, placement and appearance are controlled by the scene. Credit is retained here even though CC0 does not require attribution.

The GLB contains a skinned mesh with self-contained materials and animation clips. The race uses the `Gallop` clip (0.583 seconds); `Idle` is also available. The asset is Y-up and faces +Z. Each horse instance needs an independent cloned skeleton, while geometry can be shared.

The Three.js example horse from ROME is **not** used: that separate artwork has a different licence from the Three.js software library.
